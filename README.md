## ⭐ Featured project — Boreal Marché Customer Intelligence

An end-to-end bilingual retail decision-support application developed as a solo capstone project. It combines a temporally evaluated retention model, association-rule basket recommendations, and a grounded policy assistant with explicit privacy and human-review boundaries.

- **Public reproduction package:** [Portfolio repository](https://github.com/AIQwerty-practice/boreal_marche_portfolio_package)

Highlights:

- Python, FastAPI, Docker, AWS EC2, Systems Manager, GitHub Actions, and a bilingual web interface.
- Temporal model validation, sigmoid calibration, controlled campaign-threshold analysis, and documented limitations.
- Local document retrieval using TF-IDF, character n-grams, cosine similarity, approved bilingual policy documents, and cited responses—without LangChain, an embedding service, or a vector database.
- Measured API performance, proxy-group allocation review, model/data cards, governance documentation, and a controlled AWS grading deployment.
